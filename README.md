# Тестовое задание: QA Automation (UI)

Автоматизированное E2E-тестирование пользовательского интерфейса (добавление товара в корзину) на сайте Wildberries.

📊 **Allure Отчет:** [Посмотреть актуальный отчет](https://merkuzio88.github.io/wb/)

## 🛠 Стек технологий
* **Java 17** & **JUnit 5** — язык и тестовый фреймворк
* **Selenium WebDriver 4** — управление браузером (Chrome)
* **Maven** — сборка и управление зависимостями
* **Allure Report** — генерация подробных отчетов по тестам
* **GitHub Actions & Pages** — CI/CD пайплайн и хостинг отчетов

## 🏗 Архитектурные решения
1. **Паттерн Page Object Model (POM):** Логика взаимодействия с веб-элементами (`ProductPage`, `CartPage`) строго отделена от тестовых сценариев. Это обеспечивает читаемость и переиспользуемость кода.
2. **Явные ожидания (Explicit Waits):** Использован `WebDriverWait`. Скрипт дожидается фактической кликабельности и видимости элементов, полностью исключая нестабильные жесткие задержки (`Thread.sleep`).
3. **Стабильные XPath:** Локаторы составлены с привязкой к конкретным смысловым блокам страницы, чтобы отсечь скрытые элементы верстки и избежать ложных срабатываний.
4. **Умный запуск (Smart Headless):** Тест автоматически переходит в фоновый (headless) режим при запуске на серверах CI/CD, но открывает окно браузера при локальном запуске.

## ⚙️ CI/CD пайплайн (GitHub Actions)
* **Автозапуск:** Тесты автоматически прогоняются при каждом `push` в основную ветку.
* **Ручной запуск:** Реализована поддержка `workflow_dispatch`. Запустить тесты можно одной кнопкой во вкладке **Actions** -> **Run workflow**.
* **Отчетность:** После завершения прогона Allure-отчет автоматически генерируется и публикуется в ветке `gh-pages`.

## 🚀 Инструкция по запуску локально

### 1. Запуск тестов
Для запуска тестов с открытием браузера выполните команду в корне проекта:
```bash
mvn clean test
```
*💡 Для запуска в фоновом режиме (без графического интерфейса) добавьте флаг:*
```bash
mvn clean test -Dheadless=true
```

### 2. Просмотр отчета
После завершения тестов сгенерируйте и откройте Allure-отчет:
```bash
mvn allure:serve
```
Отчет автоматически откроется в браузере. В нем задокументированы подробные шаги (Steps) на русском языке.
